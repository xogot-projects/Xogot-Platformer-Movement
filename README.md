# Smooth & Customizable Platformer Movement (Xogot Tutorial)

This project demonstrates how to build smooth, precise, and fully customizable 2D platformer movement **entirely in Xogot** — the iPad port of the Godot game engine.

This tutorial walks through the process of implementing professional-grade movement mechanics step by step — from basic acceleration to advanced jump physics.

---

## Features

- Responsive **acceleration and deceleration**
- Physics-based **jump velocity** and **gravity** using projectile motion equations  
- **Coyote Time** and **Jump Buffering** for smoother control  
- **Variable Jump Height** and fully tweakable parameters  
- Works directly on **iPad and iPhone** via Xogot  
- Compatible with **Godot 4.x**

## How to Use

1. Download or clone this repository:
   ```bash
   git clone https://github.com/xogot-projects/Xogot-Platformer-Movement.git

2. Or [download the ZIP directly](https://github.com/xogot-projects/Xogot-Platformer-Movement/archive/refs/heads/main.zip).

3. Open the project in [Xogot](https://apps.apple.com/us/app/xogot-make-games-anywhere/id6469385251) on iPad or iPhone.

4. Run the main scene to explore the movement system, or open `player.gd` to review the implementation.
